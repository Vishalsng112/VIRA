# VIRA Family Client

Flutter client for the local VIRA server. It currently supports:

- connecting to a VIRA server with the existing session authentication;
- household discovery and automatic first-household provisioning;
- pulling and pushing versioned household notes through `/api/v1/sync`;
- sending questions to VIRA through the existing `/chat` endpoint;
- Android, iOS, Linux, and web targets generated by Flutter.

Run it from this directory:

```bash
flutter pub get
flutter run -d chrome       # or android, ios, linux
```

For a device or browser that cannot resolve `localhost`, set the server URL to
the host's LAN address (for example `http://192.168.1.20:8000`). The server
must be configured with `auth.https_only: false` for local HTTP development.

The server stores family data in its existing SQLite database. Notes are
transferred as ordered sync changes, so additional offline storage and secure
credential storage can be added without changing the HTTP contract.
