## Current priority: Phase 1 — Positioning and proof

The immediate goal is a clear public story and a reproducible five-minute demo:

1. Say what VIRA is today, who it is for, and what is not built yet.
2. Prove the working path with a real Chatbot + tool + read-only database demo.
3. Publish the security and privacy evidence.
4. Keep the roadmap and repository metadata in sync.

See [Five-minute proof](user/demo.md) and [Security overview](user/security.md).
